# 项目主页设计原则

本目录维护 **Suchenl 个人主页的长期设计原则**，不是临时 TODO、实验日志或一次性改版说明。原则文档默认使用简体中文，必要术语、代码路径、官方名称保留原文。页面功能实现和具体文章内容可以持续迭代，但不得无理由偏离已确认原则。

## 目录

| 设计原则 | 管辖范围 | 状态 |
|---|---|---|
| [论文解读设计原则](PAPER_NOTES.md) | 论文解读专题、阅读体验、论文模板、研究脉络与证据表达 | 已确认，持续实施 |

## 维护纪律

1. **一项设计决策只有一份正式原则**：更新时修改原文，不创建“新版”“补丁版”的平行文档。
2. **中文为主、英文为辅**：不向公众写“你之前说过”等私人对话式文字；使用作者面向读者的研究者口吻。
3. **原则与状态分离**：原则表达目标和验收要求；某项实现尚不支持时，在实现记录中诚实注明，不把规划描述为已上线。
4. **遵守唯一数据源**：论文正文在 `knowledge/papers/`，设计原则在本目录；不用前端生成第二份文章副本。
5. **任何重要调整先评估现有能力和兼容性**：保留旧 URL、图示、笔记及人工研究判断。需要修改时逐步核验，不大规模未经视觉验证地重排。
6. **公开边界**：私人仓库、未公开论文、实验与内部资料不得自动进入公开页面。
7. **验收**：至少运行知识校验和网站构建；涉及排版必须检查桌面与移动端，尤其目录、长公式、横向表格、SVG 与语言切换。
