# 个人知识体系与真实知识网络：设计原则

> 适用于 /knowledge/，以中文为主，尊重唯一公开 Markdown 源与原有 Research 深链接。此文是原则，不是功能完成声明。

## 一、展示范围

知识网络 **只展示已经在公开知识库中存在、且拥有可阅读正文的知识**。领域节点必须至少有一条已收录文章；专题节点必须对应实际存在的专题 README；单篇文章节点必须与可访问的 canonical Markdown 一一对应。

**禁止** 根据规划、推测、GPT 想象、尚未整理的私人笔记或空 taxonomy 项预先制造“未点亮”节点。数学、工程、生活等其他领域未来可以加入，但必须先有可审核的正式公开文章，之后再自动生长出真实节点。

尚未覆盖的学科不属于当前图谱的可量化“空白”。“薄弱连接 / 待深入学习”只能指 *已收录节点* 的内容密度、人工阅读状态或明确真实链接的情况。

## 二、真实关联

- `belongs_to`：文章的显式 `domains` 与确有文章的领域之间的分类边。
- `references`：两个已存在的公开 Markdown 之间作者明确写出的链接，或人工标注的 `related`。不能从标题相似度自动生成关系，更不能将一般性引用伪装成先修依赖或因果。
- 单篇文章有唯一 canonical URL，旧 /research/、/paper-notes/ 等路由继续有效。
- 计数与节点数据由 Astro 构建时直接读取 `knowledge/`，不在浏览器存第二份知识正文；新增内容后再构建才会出现新节点。

## 三、图谱关系的严格语义

- `belongs_to`：只表示 frontmatter 已写明的领域归属；概览可用少量淡线提示层级，其他视图不显示放射线。
- `topic_contains`：专题 README 和其真实 reviews/ 子文章之间的目录归属；不再混同正文引用。
- `references`：正文存在明确的 Markdown 内链，边记录链接文本和起点 URL；只能表示「作者引用过」，不能直接声称理解上的前置或因果。
- `semantic`：人工编写的 related 元数据，保留 compares/requires/extends/questions/supports 等类型及 note 原文；要区别于普通引用。
- `reading_step`：经过校验的学习路径 steps 列表中的真实条目，保留 why 与来源；不等同所有人的强制学习顺序。
- 每个节点只能来自现存公开文章或包含文章的已有领域；每一条边都保留可访问的出处。搜索发现未收录主题只能反馈「没有结果」，不可自动造点。

## 三、视觉和交互

- 参考 Obsidian Graph 的局部关联高亮和缩放/平移、InfraNodus 的聚焦阅读、Heptabase 的知识卡片逻辑；设计应具备自己的简约风格，不直接复制商业产品界面。
- 主图是知识库页面最核心的可视化，宽大且可见，不是背景装饰。支持鼠标/触屏平移缩放、节点拖动、双击聚焦、一跳关联高亮、搜索、按实际文章类型筛选、键盘操作及可读的正文入口。
- **渐进式阅读**：默认的概览只显示真实领域、已有专题和按真实引用度选择的部分知识入口；「完整网络」显示全部已收录正文；点领域进入领域视图；点文章进入一跳局部视图。不同层级都必须提供清晰的返回方式。
- **解释关系**：节点详情必须用简短语句标明连接类型、出处与链接方向，让读者能够分辨分类、目录、引用、人工判断和实际学习路径。
- **发现与搜索**：搜索应提供可以直接打开的真实结果列表，不能只是把其他节点变暗；区域卡片提供实际可访问的文章入口。
- **空间布局必须有可解释的依据**：领域节点根据现有跨领域引用连接优化相对排列；文章节点经过确定性的力导向布局，由原文引用（强吸引）与领域归属（弱吸引）共同驱动，并以节点排斥/防碰撞保持可读。黄金角只允许作初始位置，绝不当成最终知识关系。
- **禁止误读距离**：位置仅是网络布局近似，不是训练得到的语义 embedding，也不表示科学上的相似度、因果或先修关系。页面必须显示“领域归属 / 正文引用”的边类型说明，并向读者解释为什么节点会这样摆放。
- 浏览性能优先：使用单个 animation frame 插值摄像机，过滤、悬停只操作 DOM 状态；大量节点时应依据性能实际情况再考虑 Canvas/WebGL，而非为性能增加依赖。
- 图外仍提供可访问的真实领域目录；任何重要知识链接不得只存在于 SVG 中。减少动态效果设置必须生效。
- 不制造未收录节点、不用统计占比冒充全人类知识覆盖比例；色彩只区分现有领域，学习标记独立显示。

## 四、学习与 AI

- **已公开**：文档可访问，不代表内容充分，更不代表作者/读者已经学会。
- **已学习**：只能由当前使用者主动标记，保存在其本机浏览器，不得作为网站作者本人对外宣称的能力；跨设备同步尚未实现。
- **AI 深入学习任务**：只能基于所选的已存在节点生成可复制、需人工核验的研究/学习任务。不得把 AI 草稿直接推送到公开主页，不得直接提升人工学习标记。
- 维护闭环为：选择已收录知识 → 学习、核验原文和原始来源 → AI 辅助补充该真实主题 → 作者审查并决定是否更新唯一正文 → 图谱跟随内容变化。

## 五、隐私与边界

公开仓库不存内部研究、私人聊天、未公开论文、实验数据以及隐含个人学习历史的配置。图谱与目录只读取明确允许公开的资料。

## 六、验收

- 不出现 planned、future、empty 类虚构节点；每个专题/文献链接都能打开原有公开正文。
- 文章分类及 Markdown 引用自动构建图；测试至少包含真实机器人控制、深度感知等现有内容。
- 真实桌面和移动端测试覆盖搜索、缩放、键盘选择、学习标记、正文链接、侧栏关闭与无页面水平溢出。
- 旧研究库、论文解读、博客、产出和经历无回归；CI build 与浏览器 smoke 必须分别通过。
- Chrome 自动化成功不代表已实测 Safari、iOS VoiceOver 或大规模千节点图谱，应明确区分。
