# 个人公开知识库：目录与卡片设计原则

> /knowledge/ 当前采用「领域卡片 + 可展开目录树 + 文章卡片 + 文本检索」，不再把关系图作为主入口。中文优先、英文辅助；私有研究不进入公开站点。

## 核心目标

读者打开知识页面应能立即知道：这里有哪些真实领域、每个领域有哪些实际专题、每篇文章讲什么、如何直接进入阅读。发现知识的流程应符合普通文件目录和内容网站的直觉，而不是先理解图谱术语、节点坐标或拖拽手势。

## 首页信息层级

1. **领域卡片**：只展示确有公开正文的领域，可看到真实收录数、说明和已收录子方向；卡片可直接筛选该领域。
2. **层级目录**：左侧 \`领域 → 子方向\` 可展开、可键盘操作。目录操作过滤右侧文章列表，不生成新的文章副本。
3. **正文卡片**：文章标题是主要链接；展示真实类型、所属领域和已有可信摘要，点击即进入原 canonical URL。
4. **搜索与类型**：文本检索标题、别名、摘要、领域；类型下拉为次级筛选。结果计数和空结果解释清晰。
5. **完整阅读路径**：保留 /research/、/paper-notes/、/questions/ 与全部文章的旧 URL；已公开内容为唯一来源。

## 边界与取舍

- **撤下知识星图**。曾尝试的力导向图、领域放射线、局部聚焦、学习进度光点等未改善检索体验，不能作为默认展示；不要继续在当前页面迭代同类视觉。
- 不预设不存在的学科或专题，不为填满导航制造空节点。新增真实公开正文后，根据元数据自动更新目录与列表。
- 图谱关系类型本身可以作为未来研究/知识组织的内部材料，但前台阅读页面不再暴露关系图和渲染器。
- 不把 AI 生成、检索次数、页面访问量误认为已掌握。当前主页不收集也不公开个人学习进度。
- 用户的私人仓库、实验、未公开论文和内部工作严禁通过自动化进入公开主页。
- 避免为 UI 增加数据库、图引擎或不必要的第三方运行依赖。

## 视觉与可用性

浅色与深色都使用与个人主页一致的 CSS 主题。卡片具有足够可读的标题和摘要，状态、领域及文章类型不靠彩色小点猜测。电脑端目录在左；手机端目录改为自然排列的可展开树，不与文章列表叠层。全站支持 320px、390px 及桌面宽度，键盘导航与可见焦点，普通链接可在新标签页打开。

## 验收

- 首页不出现 SVG 知识网、力导向图和虚构节点；真实领域卡片、目录、搜索及文章列表可以使用。
- 真实 robot-control 等专题链接存在；筛选领域/子方向、搜索、清除条件、加载更多都可用。
- 原研究阅读器、论文、问答、博客、产出及经历无回归；通过 Astro 构建与浏览器回归。
