# 个人知识库：统一目录与阅读路径设计原则

> 适用于公开个人知识库 /knowledge/ 页面。中文优先、英文辅助；私有研究与未公开材料不进入公开仓库。

## 定位

Knowledge 是日常知识浏览的唯一入口，不是与 Research、论文解读、问题与探索平行的第四套索引。**研究是知识领域；论文解读、技术问答、问题与探索是内容类型。** 不同入口最终都能打开同一份 Markdown 正文。

## 信息架构与交互

1. **一个目录**：左侧「领域 → 子方向」可展开；右侧只有一套真实文章卡片。取消重复的顶部领域卡片及互相跳转的知识入口。
2. **原地筛选**：选择目录、输入关键词、选择类型只更新当前页面结果，不主动滚动到别处，也不跳往另一个目录。
3. **可恢复的上下文**：URL 的 scope、type、q、limit 保存筛选，允许分享，浏览器前进/后退应恢复状态。
4. **直接阅读**：卡片标题和阅读按钮打开既有、唯一的文章 URL。通过有限的 source=knowledge 上下文，文章顶部与底部都有返回原筛选目录的链接。
5. **同一知识、专用工具**：/research/ 保留高级全文检索、阅读状态与论文对比；/paper-notes/ 和 /questions/ 保留历史页面与书签，但不再作为日常导航的多个并列知识库。论文/探索在 Knowledge 内直接按 type=paper 或 type=exploration 筛选。
6. **统一定位**：文章面包屑按「知识库 → 领域 → 子方向 → 类型」组织，不因保留旧 /research/... canonical URL 而引导用户跳回另一套目录。

## 视觉设计

电脑端左树右卡片；手机端自然排列，目录在文章前并可展开。标题、分类、简介和正文链接清晰。支持浅色/深色、键盘焦点、320px 与 390px 宽度，不以装饰动画替代可用性。

## 内容边界

- 只使用已经公开的 Markdown 与 knowledge/taxonomy.json，不虚构领域、知识节点、统计或未来选题。
- AI 自动生成不代表已学习或已掌握；个人浏览历史、内部实验、私人仓库与未公开论文不得自动公开。
- 维持唯一正文；不同阅读入口引用同一事实来源。

## 必要验收

- 知识浏览时目录、类型、搜索都原地筛选，不造成意外跳转/滚动。
- URL 可分享、前进后退可恢复；文章顶部和底部回到此前筛选。
- 旧 /research/...、/paper-notes/、/questions/ 链接保持有效。
- 构建、静态检查、320px/390px/1440px 浏览器回归分别通过。
